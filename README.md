

# bioinformatics-coding-practice

My journey of learning bioinformatics with Python, Linux/Termux, and reproducible data workflows.

## Tools & Environment
- **Linux / CLI:** Termux (Android) with Bash, `git`, `wget`, `curl`, and `nano`
- **Python & Notebooks:** Google Colab & Biopython
- **Version Control:** Git & GitHub

## Repository Structure
- `data/` — Read-only input sequences and small reference files
- `scripts/` — Python and Bash scripts for sequence analysis
- `results/` — Generated summaries, tables, and plots

## Planned Practice Projects
1. **Viral Genome Composition & ORF Finder** — GC% calculation and Open Reading Frame extraction
2. **Cross-Species Protein Profiler** — Comparing molecular weight, pI, and instability index
3. **3D Active-Site Distance Analyzer** — Measuring residue distances from PDB structures
